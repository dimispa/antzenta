# Ατζέντα Εκπαιδευτικού

Εφαρμογή web (PWA) για iPhone, Android και υπολογιστή. Δουλεύει χωρίς διαδίκτυο.

- **Αρχική:** τα τμήματα σε στήλη αριστερά και τα μαθήματα κάθε τμήματος δεξιά.
- **Μάθημα:** τρεις στήλες.
  1. **Την προηγούμενη φορά:** τι έγινε στο τελευταίο μάθημα που πραγματοποιήθηκε.
  2. **Προγραμματισμός:** τι θα κάνετε· αποθηκεύεται αυτόματα.
  3. **Τι έκανα τελικά:**
     - «Το μάθημα έγινε»: ενημερώνει τη στήλη 1 και αδειάζει τον προγραμματισμό.
     - «Δεν πραγματοποιήθηκε»: έκτακτος σύλλογος, εκδρομή, μάθημα από άλλον εκπαιδευτικό κ.λπ. Η στήλη 1 και ο προγραμματισμός μένουν ως έχουν.
- **Υλικό:** ο φάκελος κάθε μαθήματος στο OneDrive.
  - Μπορείτε να περιηγηθείτε, να ανοίξετε αρχεία σε πλήρη οθόνη και να αποθηκεύσετε αρχεία στη συσκευή για χρήση χωρίς διαδίκτυο.
- **Συγχρονισμός** μεταξύ συσκευών μέσω ενός αρχείου στον φάκελο της εφαρμογής στο OneDrive (`Εφαρμογές/…/atzenta-data.json`).

## Δομή

| Αρχείο | Ρόλος |
|---|---|
| `js/model.js` | Πυρήνας: στήλες, «έγινε / δεν έγινε», συγχώνευση συσκευών (καθαρές συναρτήσεις) |
| `js/store.js` | Κατάσταση και ενέργειες· κάθε αλλαγή γράφεται αμέσως στη συσκευή |
| `js/db.js` | IndexedDB: δεδομένα, ρυθμίσεις, αρχεία εκτός σύνδεσης |
| `js/sync.js` | Συγχρονισμός με OneDrive (κερδίζει η πιο πρόσφατη αλλαγή, με έλεγχο σύγκρουσης eTag) |
| `js/onedrive.js` | Σύνδεση λογαριασμού Microsoft (MSAL) και Microsoft Graph |
| `js/ui/*` | Οθόνες (Preact + htm, χωρίς build) |
| `sw.js` | Service worker: η εφαρμογή ανοίγει χωρίς διαδίκτυο |
| `js/vendor/` | Preact/htm 3.1.1 και MSAL Browser 4.30.0 (αποθηκευμένα τοπικά) |

## Τοπική δοκιμή

```
python tools/serve.py
```

Ανοίξτε το http://localhost:8765. Οδηγίες χρήσης και εγκατάστασης: μέσα στην εφαρμογή (εικονίδιο «?», `#/help`). Τα tests είναι στα `/tests/index.html` (πυρήνας) και `/tests/sync.html` (συγχρονισμός).

## Νέα έκδοση

Όταν αλλάζουν αρχεία:
- αυξήστε το `VERSION` στο `sw.js`·
- προσθέστε στη λίστα `FILES` τυχόν νέα αρχεία.

Οι συσκευές θα δείξουν «Υπάρχει νέα έκδοση — Ανανέωση».

## OneDrive

Χρειάζεται μία εγγραφή της εφαρμογής στη Microsoft (Entra → App registrations, τύπος **SPA**). Το Redirect URI είναι η διεύθυνση της εφαρμογής. Το «Application (client) ID» μπαίνει:
- είτε στο `js/config.js`, ώστε να ισχύει για όλες τις συσκευές·
- είτε στις Ρυθμίσεις κάθε συσκευής.
